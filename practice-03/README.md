## 5. Организация кода

- `src/task-service.js` — чистая бизнес-логика манипуляции задачами и расчет статистики `getTaskStats`. Не зависит от DOM.
- `src/task-selectors.js` — чистая функция `getVisibleTasks(tasks, filter)` для отбора отображаемых задач (`all`, `pending`, `completed`).
- `src/task-view.js` — создание карточек (`createTaskElement`), замена списка (`renderTaskList`), рендер сводки (`renderSummary`) и пустого состояния (`renderEmptyState`).
- `src/main.js` — точка входа клиентского приложения: хранит `currentTasks` и `currentFilter`, единовременно подписывается на события через делегирование (`handleTaskListClick`, `handleFilterClick`) и обновляет интерфейс вызовом `renderApp()`.
